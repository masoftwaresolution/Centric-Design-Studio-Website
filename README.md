# 🏛️ Centric Design Studio

A modern, responsive architecture and interior design website built with **React**, **Vite**, and **Tailwind CSS**. This project was created as a demo concept for **Centric Design Studio** to showcase a clean, elegant, and professional web presence.

---

## ✨ Features

- Modern & Responsive Design
- Home, About, Services, Projects, Studio & Contact Pages
- Professional Architecture Portfolio
- Responsive Navigation
- Project Showcase
- Contact Form with EmailJS
- Smooth User Experience
- Mobile Friendly Layout
- Clean UI/UX Design

---

## 🛠️ Tech Stack

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/centric-design-studio.git
```

Navigate to the project folder:

```bash
cd centric-design-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
